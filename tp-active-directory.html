Active Directory

Un seul point pour organiser l’entreprise.

J’ai créé un domaine Windows capable de centraliser les comptes, les postes, les fichiers et les règles de sécurité d’une entreprise fictive : Technova.

Windows ServerAD DSGPO
Le besoin

Éviter la dispersion

Gérer chaque poste et chaque compte séparément devient vite ingérable.

La réponse

Un domaine commun

Les identités, les postes et les règles sont regroupés dans un même environnement.

Le résultat

Une sécurité cohérente

Les mêmes règles s’appliquent partout, sans refaire les réglages poste par poste.

Le fonctionnement

Un chef d’orchestre pour le réseau.

Le contrôleur de domaine devient le point de référence pour savoir qui se connecte, sur quel poste, avec quelles règles.

Ce que j’ai fait

Centraliser sans compliquer.

01

Créer le domaine

J’ai installé le contrôleur de domaine Technova, avec son service DNS : les machines peuvent désormais se reconnaître et se rejoindre.

02

Structurer les personnes

Les utilisateurs, groupes et ordinateurs sont organisés par service. Cette structure rend les droits et les règles faciles à cibler.

03

Appliquer les bonnes règles

Les GPO imposent notamment un verrouillage de session, une politique de mot de passe et une identité visuelle commune.

Ce que ce TP m’a appris

Active Directory rend une entreprise plus simple à administrer : un nouvel arrivant, un nouveau poste ou une nouvelle règle peut être géré de manière cohérente et traçable.
